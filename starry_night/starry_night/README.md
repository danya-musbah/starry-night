# The Starry Night — Living Painting 🌌

لوحة **ليلة النجوم (1889) لفان غوخ** كلوحة حيّة متحركة، مرسومة بالكامل برمجياً
بـ Python + Pygame — بدون أي صور أو فيديوهات جاهزة، وبدون API أو مكتبات مدفوعة.

## التشغيل

```bash
pip install -r requirements.txt
python main.py
```

(على macOS/Linux قد تحتاج `python3` و`pip3`.) التحميل الأولي يستغرق نحو 2–5 ثوانٍ
أثناء «رسم» عشرات الآلاف من ضربات الفرشاة، ثم تبدأ اللوحة بالحركة بـ 60 FPS.
تعتمد اللعبة على `pygame-ce`، وهو بديل متوافق مع واجهة Pygame، بما في ذلك Python 3.14.

## الاختصارات

| المفتاح | الوظيفة |
|---|---|
| `SPACE` | إيقاف / استئناف الحركة |
| `↑` / `↓` | زيادة / إنقاص السرعة (0.25× إلى 3×) |
| `G` | تشغيل / إيقاف توهج النجوم والقمر والـ Bloom |
| `F` | ملء الشاشة |
| `R` | إعادة ضبط المشهد |
| `ESC` | خروج |

## خيارات إضافية

```bash
python main.py --save-frame still.png --frames 200   # حفظ لقطة ثابتة
python main.py --bench --frames 300                  # قياس زمن الإطار
```

## كيف تعمل؟

* **ضربات الفرشاة** (`brush.py`): كل ضربة صورة صغيرة مولّدة رياضياً بشعيرات متفاوتة السطوع،
  فجوات «فرشاة جافة»، ذيل مدبّب ولمعة طلاء، وتُخزَّن بـ 24 زاوية.
* **الدوامات** (`composition.py`, `sky.py`): حقل تدفق مبني من دوامات + الشريط الموجي الطويل.
  تُرسم الضربات على **منحنيات بارامترية**: حلزونات لوغاريتمية `r = r₀·e^(bθ)` ومنحنى
  `y = f(x)` للشريط، إضافة إلى عشرات الآلاف من الضربات الموجَّهة بحقل التدفق.
* **الحركة**:
  * ثلاث نسخ مرسومة من السماء تتمازج ببطء (ارتعاش ضربات الفرشاة وتغير الإضاءة).
  * ~1500 ضربة حيّة تنجرف مع التدفق وتدور حول النجوم، وتتلاشى بسلاسة.
  * خريطة إضاءة تدور حول الدوامتين الكبيرتين.
  * نجوم: نبض مستقل لكل نجمة، هالات تدور، حلقات توهج تتسع وتتلاشى، وشرارات تدور.
  * قمر: توهج متدرج، هالات متعاكسة الدوران، وميض خفيف.
  * قرية: إضاءة نوافذ هادئة، ضباب ليلي منجرف، وسرو يتمايل بشرائح مرتبطة بالارتفاع.
* **الطبقات**: سماء ← جزيئات ← قمر ونجوم ← Bloom ← جبال/تلال/قرية ← ضباب ← نوافذ ← سرو ← ضباب أمامي.
* **الأداء**: يضبط البرنامج عدد الضربات الحيّة تلقائياً ليحافظ على ~60 FPS على الأجهزة الأضعف.
